# Unmute Windows 下载

[下载最新正式版](https://github.com/JJ-YOYO730/unmute-downloads/releases/latest)

- **安装版**：完成录音后，从 Windows 托盘退出 Unmute，再运行下载的 Setup.exe 覆盖安装。软件继续使用本机已有的录音、纪要、声纹和设置。
- **便携版**：完整解压 ZIP 后运行 MeetingAudioAgent.App.exe。
- **校验**：使用发行页附带的 SHA256SUMS.txt 核对文件完整性。
